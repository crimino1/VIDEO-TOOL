On 2026-11-12 the user asked for a new animation style for "Unseen", because the photo cut-out documentary look is now used by many channels. They sent 4 flat vector stock stills: a seabed with light rays, a family by a farmhouse at sunset, a cartoon reef with a sunken ship, and a fishing boat on a flat sea.

Built a 25 s silent test in VIDEO-TOOL/flat-test. assets/js/flat.js is a canvas rig with:
- a flat cartoon orca with a body warp for fluke strokes
- cartoon people with walk, point, wave and blink
- three scenes: seabed, boat and shore

Output: done/unseen-flat-style-test.mp4. User approved it on 2026-11-12 ("Yes, use this style"); it is now the default look for new Unseen films. Still to ask on which channel it is for (Unseen Kingdom or Unseen By Eye).

Details are in the channel-style guide unseen-kingdom.md under "Rules from feedback". Related: [[orcahuman-project]], [[trench-project]].
